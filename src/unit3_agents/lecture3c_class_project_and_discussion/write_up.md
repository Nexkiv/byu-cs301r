# 3c Homework Instructions

My plan is to build an agentic web-service. This will work as a study
tool that will be able to combine student notes, lecture slides, and
homework problems to create a rag model that can be used by a student
to deepen their understanding of the topic by making possible to
generate flashcards and hold conversations relating to the subject area.
I spent three hours hashing out a plan using the perplexity research
agent and I have attached it as `INITIAL_PLAN.md`. It contains a
description of how I will implement a Minimum Viable Prototype (MVP).
The reason I chose this project is becaus eit is something that I
already do to prepare for exams. I also think that by combining
deterministic tools and agentc tools this web app coul be very
effective.
