# LLM Evaluation Quadrants

|                                 | Objective                                         | Subjective                                                         |
|---------------------------------|---------------------------------------------------|--------------------------------------------------------------------|
| **Per-example ground truth**    | exact match, accuracy, extraction correctness     | judged against a reference answer or target criteria               |
| **No per-example ground truth** | format/schema checks, length limits, tool success | judged on helpfulness, clarity, coherence, tone, or rubric quality |
